# 交接模板

当任务需要交给另一个开发者或 AI 模型继续处理时，建议使用本文模板。

## 标准模板

```text
目标：
已阅读文件：
已修改文件：
关键不变量：
已运行验证命令：
观察到的结果：
未决问题：
```

## 填写建议

- **目标**：写清楚本次任务期望完成的最终状态。
- **已阅读文件**：列出实际读过且影响判断的文件。
- **已修改文件**：列出所有变更文件。
- **关键不变量**：记录端口、单位、边方向、求解器路径等风险点。
- **已运行验证命令**：记录命令和结果，不要只写“测试通过”。
- **观察到的结果**：记录残差、输出文件和异常现象。
- **未决问题**：明确后续还需要谁处理什么。
