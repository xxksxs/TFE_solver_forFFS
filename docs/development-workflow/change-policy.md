# 代码与文档修改规范

适用于源码、构建配置、正式文档和项目验证约定。每项可独立审查的变更在 [changes/](../changes/README.md) 留一条记录，同一任务的连续试验更新同一条。

## 修改前

- 读取 [工程参考](../engineering-reference.md)、对应接口和专题权威页，注明目标、影响范围、接口或数学不变量以及验证计划。
- 检查工作树，保留其他任务的修改。涉及方程、变量或端口模型时，记录公式来源、符号、适用条件和现行实现入口。
- 确认 AEDT、网格、激励和参考数据来自同一算例。确定基准指标与接受条件。

## 修改中

- 使用正常 CLI、工厂和既有接口完成接线。临时实验放在独立工作目录。正式资料归入 `docs/`。
- CLI、默认值、输入输出、公式或适用范围变更时，同批同步专题权威页。历史结果保留其编译、网格、后端、频率和选项。
- 文档中的理论推导、计划和实测结果要能区分。未核实的接口、结果或来源标记为待核实。
- 涉及文档迁移、合并、改名或删除时，先核对独有信息及引用，再按已批准的路径操作。

## 修改后

| 变更类型 | 最低核验 |
|---|---|
| 导航或文档 | 检查相对链接、标题锚点、命令或引用。若改写当前行为，核对源码或相关验证记录。 |
| 构建与依赖 | 验证受影响的构建组合和测试注册。注明依赖不可用的组合。 |
| CLI、算法、端口或求解器 | 从正常 CLI 运行代表算例并检查残差、状态和输出。有数值改动时按需要复核同网格 Direct、局部关键频点和 HFSS 参考。 |
| 性能 | 同网格、频率、线程、后端和输出设置下记录耗时、峰值内存及复测口径。 |

填写变更记录，注明现行文档、测试命令与结果、兼容性影响、失败或未验证项。已有工作树的实验功能须带上版本状态。审查时同时检查实现、使用说明与证据。
