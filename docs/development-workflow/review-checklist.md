# 审查清单

代码或文档修改完成后，建议按以下清单审查。

## 构建和运行

- **构建**：受影响配置能编译。
- **CLI**：用法和默认行为仍清晰。
- **单频点**：至少一个频点能完成求解。
- **输出**：CSV 和 VTU 按预期生成。

## 数值可信度

- **残差**：求解残差被记录并解释。
- **端口**：端口 faceId、边方向、L2 模态归一化和坡印廷功率归一化一致。
- **边界**：端口边未被 PEC 约束清零。
- **单位**：频率、坐标、波数和材料单位一致。

## 文档一致性

- **路径**：文档中提到的路径真实存在。
- **索引**：新增或移动文档后更新对应 `README.md`。
- **入口**：顶层入口能引导到详细文档。
- **语言**：新增文档应保持中文撰写。
