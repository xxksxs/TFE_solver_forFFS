# 开发流程文档索引

项目修改统一遵循[代码与文档修改规范](change-policy.md)，并在[变更记录](../changes/README.md)留痕。本目录提供具体流程和审查清单。

新 Agent 从[快速接手指南](agent-handoff.md)开始。任务交接时使用[交接模板](handoff-template.md)。

## 阅读顺序

1. **编辑前准备**：阅读 `before-editing.md`。
2. **编辑中约束**：阅读 `during-editing.md`。
3. **编辑后检查**：阅读 `after-editing.md`。
4. **审查清单**：阅读 `review-checklist.md`。
5. **交接模板**：阅读 `handoff-template.md`。

## 文档列表

- **`before-editing.md`**：如何选择最小上下文和任务文档。
- **`during-editing.md`**：代码修改期间的边界和约束。
- **`after-editing.md`**：修改后的构建和运行检查。
- **`review-checklist.md`**：审查时应检查的项目。
- **`handoff-template.md`**：交给其他开发者或模型的模板。
- **`git-workflow.md`**：本地 Git 仓库管理约定（提交粒度、标签策略、还原与排错）。
