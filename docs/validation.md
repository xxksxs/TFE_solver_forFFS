# 数值验证说明

本文件保留为数值验证文档的兼容入口。详细内容已拆分到 `validation/` 目录。

## 推荐入口

- **索引**：`validation/README.md`
- **最小验证运行**：`validation/minimum-run.md`
- **残差预期**：`validation/residual-expectations.md`
- **端口验证**：`validation/port-validation.md`
- **S 参数验证**：`validation/s-parameters.md`
- **场可视化验证**：`validation/field-visualization.md`
- **材料和单位检查**：`validation/material-units.md`
- **常见失败特征**：`validation/failure-signatures.md`
- **验证流程**：`validation/validation-workflow.md`

## 使用建议

- 任何物理或数值相关修改后，先读 `validation/minimum-run.md` 和 `validation/residual-expectations.md`。
- 修改端口相关逻辑时读 `validation/port-validation.md` 和 `validation/s-parameters.md`。
- 修改场输出时读 `validation/field-visualization.md`。
