# 测试说明

本文件保留为测试文档的兼容入口。详细内容已拆分到 `testing/` 目录。

## 推荐入口

- **索引**：`testing/README.md`
- **构建检查**：`testing/build-checks.md`
- **CLI smoke test**：`testing/cli-smoke-tests.md`
- **输出文件检查**：`testing/output-file-checks.md`
- **建议补充的单元测试**：`testing/future-unit-tests.md`
- **回归检查清单**：`testing/regression-checklist.md`

## 使用建议

- 修改 CMake 或求解器时读 `testing/build-checks.md`。
- 修改 CLI 时读 `testing/cli-smoke-tests.md`。
- 修改输出时读 `testing/output-file-checks.md`。
- 数值相关修改后读 `testing/regression-checklist.md`。
