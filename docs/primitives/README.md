# 原语文档索引

本目录用于维护 BP-FEM 工程中的核心“原语”与数据契约。原语是跨模块共享的基本概念，例如频率、网格点、全局边自由度、稀疏矩阵、求解结果和输出文件。

如果要修改解析器、有限元装配、端口模式、线性求解器或后处理，请先阅读本目录中与任务相关的文档。

## 阅读顺序

1. **物理原语**：阅读 `physical.md`，理解频率、波数、材料、波端口和 S 参数。
2. **网格原语**：阅读 `mesh.md`，理解点、面三角形、四面体和面 ID。
3. **FEM 原语**：阅读 `fem.md`，理解边自由度、Nedelec 基函数、装配项和边界条件。
4. **线性代数原语**：阅读 `linear-algebra.md`，理解稀疏矩阵、RHS、直接求解器和 fallback 求解器。
5. **输出原语**：阅读 `output.md`，理解 S 参数 CSV、VTU 场文件和端口投影。
6. **关键不变量**：阅读 `invariants.md`，确认跨模块必须保持一致的约束。

## 文档列表

- **`physical.md`**：物理量、材料、频率、端口和 S 参数。
- **`mesh.md`**：网格数据结构和 faceId 语义。
- **`fem.md`**：H(curl) 边元、自由度、弱式装配和边界条件。
- **`linear-algebra.md`**：稀疏矩阵、求解器和 `SolveResult` 契约。
- **`output.md`**：后处理、端口投影、CSV 和 VTU 输出。
- **`invariants.md`**：修改代码前必须检查的不变量。

## 添加新原语的流程

1. 先确认新概念是否应该成为跨模块共享类型。
2. 如需要，先更新 `include/bpfem/core/Types.hpp`。
3. 更新产生该原语的解析器或构造模块。
4. 更新 FEM、线性代数或后处理中的所有消费者。
5. 在本目录新增或更新对应文档。
6. 如果影响数值结果，同步更新 `../validation.md`。
7. 如果影响命令行或输出，同步更新 `../testing.md`。
