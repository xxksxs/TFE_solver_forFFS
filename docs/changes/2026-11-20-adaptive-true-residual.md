# 真实残差自适应扫频原型

工程 MGAWE 以局部 Taylor 矩构建统一基，在线求解用同一网格、材料、边界约束和真实端口频率律投影得到的系统。真实和 Taylor 残差使用同一个重构场。稀疏矩阵向量积和端口秩一作用共用全阶仿射数据，每个残差频点无需全阶分解。WCAWE 的诊断选项测量现有论文 ROM 的两种残差。参数、截止约定和输出字段见[工程模式的真实算子残差](../optimization/awe-family/paper-reproduction.md#工程模式的真实算子残差)。

## 同网格验收

IOStructure 默认网格、90–100 GHz、101 点，MSVC Release、零阶棱元、数值波端口、单线程 PARDISO。使用 `--mgawe-adaptive-true-residual --mgawe-true-residual-tolerance 1e-3 --mgawe-points 3 --mgawe-order 12`。实际展开频率为 95 和 100 GHz，每点求解 12 个矩，ROM 维数 22。一次符号分析、两次数值分解和 24 次全阶右端项求解。最大真实相对残差为 4.74527×10⁻⁵，最大 Taylor 相对残差为 4.74666×10⁻⁵，101 个频点均满足残差要求。总用时 76.11 s，峰值工作集 2720.65 MB。

| 通道 | 对同网格 Direct 的复数相对 L2 误差 | 最大复数绝对差 |
| --- | ---: | ---: |
| S11 | 0.00000280% | 3.48664×10⁻⁸ |
| S21 | 0.007645% | 2.50633×10⁻⁶ |

全频基准使用算例库归档的 101 点 Direct 复数 CSV。AEDT 和网格与归档运行的输入一致。本轮二进制复算 90、95、100 GHz，复数 S11/S21 对归档的最大绝对差为 4.13×10⁻¹⁶ 和 3.71×10⁻¹⁸。

216 四面体波导复核了同网格 Direct、预算耗尽、零激励、跨截止、WCAWE 诊断及论文模式。阈值 `1e-10` 且只有一个一阶展开点的工况记录了四个未达标频点。7–12 MHz 跨截止烟测在 7 MHz 记录零右端项和空相对残差。WCAWE 开关诊断的复数 S 参数 CSV 逐字节一致。合成测试核对了真实与 Taylor 残差的独立计算、截止保护和零右端项。工程原型覆盖现有无损波端口，WCAWE 自动分子带取点待后续实现。

## 2026-11-21 边界复验

使用仓库 `tests/fixtures/rectangular-waveguide` 的 216 四面体网格、零阶棱元、单模数值端口和单线程 PARDISO。复数 S 参数对同一构建、同一网格、同一频点逐点 Direct，零激励频点从相对 L2 指标中排除。真实残差以同频全阶系统的 RHS 无穷范数归一化。

| 9–10 GHz，一点一阶 | 1e-10 | 9.06721e-2 | 4 | 0 |
| 7–12 GHz，跨截止四阶 | 1e-3 | 1.18725e-4 | 0 | 0 |
| 7–12 GHz，跨截止且一点一阶 | 1e-3 | 3.32870e-1 | 3 | 0 |
| 截止保护区内外各一点，四阶 | 1e-3 | 15.2991 | 1 | 0 |

跨截止四阶工况在 7 GHz 标记 `zero_rhs`，相对残差留空。其余四点对 Direct 的复数相对 L2 误差为 S11 0.00001033%、S21 0.00003534%。保护区内的非零激励频点保留真实残差，Taylor 残差留空，停止原因是 `no_eligible_unmet_frequency`。全频点零激励和仅有保护区内激励分别以明确原因和退出码 1 结束。

修正三个 CLI 误用。容限 `1e-3junk` 以及把 MGAWE 或 WCAWE 的新开关用于其他扫频算法，修正前均退出 0，修正后均报错并退出 1。WCAWE 展开点零 RHS 现在在稀疏分解前明确报错。跨截止的单点 WCAWE 保留原有分支限制。WCAWE 二阶开关诊断的 S 参数 CSV 逐字节一致，诊断状态为 `diagnostic_only`。修正前后成功工况的 S 参数 CSV 逐字节一致。独立 Release 构建的三个 CTest 均通过。
