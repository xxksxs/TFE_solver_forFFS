# TFE 与混合精度求解联合验收

本轮从隔离分支统一构建和测试 AWE 系列公式对齐、原生 TFE 分块装配、MUMPS 外存与混合精度 GMRES。原生 TFE 和混合精度选项由 CLI 显式选择。主要入口见[工程参考](../engineering-reference.md)和[求解器选择](../architecture/solver-selection.md)。复现命令、验收门槛与输出检查汇总在[发布验收规范](../testing/release-validation.md)。

## 构建和物理核验

Windows x64 Release，MSVC 19.51，oneMKL 2025.3 ILP64，串行 ZMUMPS 5.9.2。应用 MKL/MUMPS 的四种开关组合各通过 4 项 CTest。执行程序从构建目录直接运行，验证了 MKL 和 Fortran DLL 部署。

均匀波导五点覆盖基阶 0/1、单线程、PARDISO、无 MKL 的 GMRES＋ILU(0)、MUMPS 外存、GMRES＋Schwarz 及混合精度 GMRES。合并回归修正了早期临时波导夹具的几何比例，将坐标按 NGMesh 导出约定用米存储。零阶最大 |S11| 为 0.01206，最低 |S21| 为 0.999927，一阶分别为 0.000248 与 0.99999997。以零阶基强制 GMRES 只跑一步时，退出码为 1，`run.json` 记录 `iteration_limit` 和真实残差，结果目录没有 S 参数 CSV。

## 迭代与低内存后端

三模滤波器 40–43 GHz，21 点、基阶 0、四线程、`--port-method tfe`。混合精度运行三次均满足 `1e-7` 真实相对残差门槛，实测最大 `9.88e-8`。相对双精度 PARDISO 的 S11/S21 最大复数绝对差为 `3.14e-8` / `2.67e-8`。两条主要路径取三次中位数，MUMPS 各运行一次。

| 配置 | 总耗时（s） | 峰值工作集（MiB） |
| --- | ---: | ---: |
| 双精度 PARDISO | 7.45 | 306.1 |
| 双精度 GMRES＋单精度 PARDISO 预条件 | 6.95 | 270.8 |
| MUMPS 外存 | 42.58 | 211.8 |
| MUMPS BLR，压缩容差 0.01 | 38.88 | 303.4 |

MUMPS 两条路径与基准的复数 S 参数最大绝对差均低于 `1.71e-12`。输出的 `tolerance` 和 `mumpsBlrTolerance` 可回读。原四子域 Schwarz 在三模滤波器上仍停在约 0.471，可用于回归失败保护。工程迭代通过的是 `pardiso-single`。这条路径含全局单精度分解，`numeric_factorization_count` 统计直接求解会话的分解，预条件器的分解会计入各频点的耗时。

## TFE 全带与深谷

IOStructure 90–100 GHz，81 个等距点、基阶 0、每端口 3 模、四线程，频率间隔 125 MHz。混合扫频使用 2 GHz 子带、每带 1 个展开点，93.960–94.030 GHz 的请求频点走精确 TFE 系统。各配置单次运行。

| 原生 `tfe-block` 路径 | S11 / S21 复数相对 L₂ | 总耗时（s） | 峰值工作集（MiB） |
| --- | ---: | ---: | ---: |
| 精确 Direct，双精度 PARDISO | 基准 | 197.21 | 2220.0 |
| 分段 MGAWE＋指定区间精确解，双精度 PARDISO | 0.07057% / 0.01225% | 61.96 | 2285.5 |
| 同一 MGAWE 配置，混合精度 GMRES | 0.07057% / 0.01225% | 72.37 | 1873.4 |

两条 MGAWE 路径对精确 Direct 的全带最大 S11/S21 幅值偏差均约 0.04284/0.00186 dB。原生 Direct 改用混合精度 GMRES 后，21 点全部收敛，最大真实相对残差为 `1.26e-8`，S11/S21 最大复数绝对差小于 `7.16e-8` / `4.22e-10`。

匹配的 21 点原生 Direct 成本为双精度 PARDISO 82.95 s / 2224.6 MiB、混合精度 GMRES 122.97 s / 1728.5 MiB。81 点 MGAWE 中，改用混合精度使峰值下降 18.0%，总耗时增加约 10.4 s。原生精确区间各自记录实际使用的线性后端和收敛状态。

用相同网格和独立 AEDT 扫频副本加密 93.960–94.030 GHz，间隔 5 MHz、共 15 点。精确 Direct 与独立构建的局部 MGAWE 都在 93.985 GHz 取得采样谷底，精确 Direct 为 −53.52779 dB，谷深差为 `2.36e-6` dB。谷值定位分辨率为 5 MHz。全带的精确区间选项使用请求点，做局部加密需在工程中另设频点。

## AWE 系列兼容性

IOStructure 90–100 GHz、41 个等距点、数值单模端口、基阶 0、四线程。复数相对 L₂ 使用同模型 Direct 作基准。HFSS 列使用仓库 CSV 的 21 个共同频点，只比较幅值。

| 方法 | 对 Direct 的 S11 / S21 复数 L₂ | 对 HFSS 的 S11 / S21 幅值 L₂ | 总耗时（s） | 峰值工作集（MiB） |
| --- | ---: | ---: | ---: | ---: |
| 双精度 PARDISO Direct | 基准 | 0.4323% / 0.1418% | 135.56 | 2162.7 |
| AWE 逐场 Padé `[16/17]` | 0.9952% / 0.1228% | 0.5538% / 0.1603% | 39.42 | 2794.1 |
| MGAWE 3 点 × 6 阶 | 0.000722% / 0.000139% | 0.4323% / 0.1418% | 35.26 | 2770.2 |
| WCAWE 16 阶，双精度 PARDISO | 0.000194% / 0.05644% | 0.4323% / 0.1204% | 29.46 | 2640.1 |
| WCAWE 16 阶，混合精度 GMRES | 0.000194% / 0.05644% | 0.4323% / 0.1204% | 32.46 | 2195.5 |

同一网格的 AWE `[12/13]`、`[13/14]`、`[14/15]` 最大复数相对误差分别为 1.151%、1.176%、1.061%，均超过 1%。本轮使用 `[16/17]`，该结果接近门槛，变更频点或模型后要重新验收。WCAWE 首轮使用默认 `1e-7` 线性容差时与 `1e-10` 的独立递推检查冲突。现行 WCAWE 迭代后端按更严的 `min(--tolerance, 1e-11)` 求离线矩，复测构足 16 维基。

## 发布范围

发布门槛包含四种构建的 16 项 CTest 和 30 个 CLI 用例，其中两个用例核验预期不收敛时的退出码、真实残差和输出保护。速度或内存收益受算例、网格、求解器及线程影响。线程型 ZMUMPS、HFSS 相位及参考面校准、IVEC pillbox 算例仍待验证。
