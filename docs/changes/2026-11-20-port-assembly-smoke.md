# 端口与装配物理基线

- 新增 [端口和装配烟测](../testing/port-assembly-smoke.md)、矩形波导夹具和 `scripts/port_assembly_smoke.mjs`。在既有 `io_parser_tests` 增加可选 `--port-baseline` 模式，保留默认测试和真实工程轻量解析入口。
- 复用数值单模和旧双模 Direct，逐频校验 $A_0,b_0$、独立端口块、模态截止、PEC、非零传输及完整可观测传播功率。报告记录输入哈希、频点和容差。
- 独立 MSVC Release + oneMKL 构建的三个 CTest 通过。四组 CLI 共 28 个频点通过，$A_0x$ 最大相对差 $2.81\times10^{-16}$，$b_0$ 差为零。端口块最大相对差 $6.18\times10^{-16}$。波导主/次截止分别为 7.48457 / 11.85288 GHz，主模传播相位最大误差 0.05501 rad。Pillbox 最小 $|S_{21}|$ 为 0.19594。功率最大偏差为单模 $2.67\times10^{-15}$、旧双模 $2.64\times10^{-4}$。
- 当前改变仅限测试、夹具和说明。旧双模偏差用于回归门槛，截止以下物理修正、单端口和完整多模散射接口留待后续。
