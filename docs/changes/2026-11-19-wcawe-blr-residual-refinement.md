# WCAWE 离线矩的残差校正

## 问题

MUMPS BLR 的压缩容差控制因子块近似。WCAWE 需要接受的矩满足原展开点方程 `A0 w = r` 的真实相对残差门槛 `1e-10`。BLR 压缩容差与最后的方程残差分别测量不同量。一般线性验收默认 `1e-7`，所以相同的右端项可能通过线性验收，递推检查仍可能失败。实际失败工况与先前的状态保护见[多波前首轮验证](2026-11-19-multifrontal-wcawe-validation.md)。

## 修改

在 `WcaweSweep::buildOffline` 中，支持复用因子的直接后端对每个矩使用 `min(--tolerance, 1e-10)` 作为真实残差目标。若首次回代的有限结果超限，计算原方程残差 `d = r - A0*w`，复用已有因子求近似校正向量 `Δw`，更新 `w += Δw` 后用原 `A0` 检查。最多两次校正，修正残差停滞或非有限时退出，超限由现有失败通道终止扫频。构基依旧保留独立递推检查。实际校正回代计入 `factorized_rhs_solve_count`。

## 复现

使用启用 oneMKL 和 ZMUMPS 的 Release 构建，在与[多波前首轮验证](2026-11-19-multifrontal-wcawe-validation.md)相同的 IOStructure 41 点和 16 阶配置下，选择 `--linear-solver mumps --mumps-mode blr --mumps-blr-tolerance 1e-8`，再用 `1e-12` 复跑。确认 `diagnostics.json` 的有效维数为 16、真实递推残差不超过 `1e-10`、复数 S 参数与同网格 PARDISO WCAWE 对齐，分解计数为 1。另用 `--wcawe-check-moments` 检查参考矩，并复跑带通滤波器的 MUMPS 外存路径。

MSVC Release，oneMKL 2025.3，串行 ZMUMPS 5.9.2。四项 CTest 均通过。
