# 文档任务

## 目标

改进入门说明、验证步骤、开发交接说明或专题文档结构。

## 优先阅读文件

- `../../README.md`
- `../overview.md`
- 当前要修改的专题文档
- 对应专题目录的 `README.md`

## 可能修改文件

- `../../README.md`
- `../*.md`
- `../architecture/*.md`
- `../development-workflow/*.md`
- `../overview/*.md`
- `../primitives/*.md`
- `../task-splitting/*.md`
- `../testing/*.md`
- `../validation/*.md`

## 验证方式

纯文档修改不需要编译。手动检查：

- 文件路径是否存在。
- 索引是否更新。
- 是否存在乱码。
- 是否记录了尚不存在的功能。

## 风险提示

- 文档必须与当前代码路径一致。
- 不要记录尚不存在的功能。
- 优先使用精确文件路径，不要使用模糊模块名。
- 新增专题文档后同步更新目录索引。
