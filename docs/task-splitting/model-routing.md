# 推荐模型分工

本文说明把任务交给不同能力模型或开发者时的建议分工。

## 小模型

适合任务：

- 文档清理。
- 命令摘要。
- 简单路径检查。
- 简单解析器正则检查。

不建议任务：

- FEM 装配推导。
- 端口模式归一化。
- 求解器数值稳定性判断。

## 代码模型

适合任务：

- 单模块内的局部 C++ 修改。
- 接口和实现同步。
- CLI 参数和输出字段维护。

注意事项：

- 必须提供明确文件范围。
- 必须提供验证命令。

## 数值模型

适合任务：

- FEM 装配。
- 端口模式。
- 求解器残差和稳定性。
- S 参数物理合理性分析。

注意事项：

- 必须阅读 `../validation/README.md`。
- 必须检查 `../primitives/invariants.md`。

## 审查模型

适合任务：

- 跨模块一致性检查。
- 文档链接检查。
- 回归清单检查。
- 风险点归纳。

注意事项：

- 审查应围绕明确不变量，而不是泛泛重读全部代码。
