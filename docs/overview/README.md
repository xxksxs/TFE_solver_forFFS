# 总览文档索引

本目录把工程总览拆成多个短文档。顶层 `../overview.md` 仍作为主入口保留。

## 阅读顺序

1. **阅读顺序**：阅读 `reading-order.md`，决定先看哪些文件。
2. **项目树说明**：阅读 `../project-tree.md`，识别源码、文档、输入资产和生成目录。
3. **文档地图**：阅读 `document-map.md`，定位专题文档。
4. **运行流**：阅读 `runtime-flow.md`，理解输入到输出的数据路径。
5. **扩展点**：阅读 `extension-points.md`，确定修改入口。
6. **安全规则**：阅读 `safety-rules.md`，确认跨模块不变量。

## 文档列表

- **`reading-order.md`**：推荐阅读路径。
- **`../project-tree.md`**：项目树和目录职责说明。
- **`document-map.md`**：文档体系和专题入口。
- **`runtime-flow.md`**：运行时数据流。
- **`extension-points.md`**：常见扩展入口。
- **`safety-rules.md`**：修改前必须遵守的规则。
