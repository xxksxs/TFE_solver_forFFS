# 文档地图

本文说明 `docs/` 下各专题目录的用途。

## 顶层入口

- **`../overview.md`**：工程主入口和兼容入口。
- **`../project-tree.md`**：项目树、目录职责、生成目录和数据流速览。
- **`../../README.md`**：构建、运行和文档入口。

## 专题目录

- **`../architecture/README.md`**：模块职责、依赖方向、求解器选择和风险点。
- **`../primitives/README.md`**：物理、网格、FEM、线性代数、输出和不变量。
- **`../testing/README.md`**：构建检查、CLI smoke test、输出检查和回归清单。
- **`../validation/README.md`**：残差、端口、S 参数、场可视化和单位验证。
- **`../task-splitting/README.md`**：按任务类型分派开发者或 AI 模型。
- **`../development-workflow/README.md`**：编辑前、中、后检查和交接模板。
