# 回归检查清单

本文列出数值修改前后的最小回归检查项。

## 构建检查

- **Release 构建**：默认 Release 构建通过。
- **Fallback 构建**：`-DBPFEM_USE_MKL=OFF` 构建通过。
- **MKL 构建**：有 oneMKL 环境时，MKL 路径构建通过。

## CLI 检查

- **帮助信息**：`--help` 正常输出。
- **单频点运行**：一个频点求解完成。
- **参数兼容**：常用参数仍可识别。

## 数值检查

- **残差**：直接求解器残差接近机器精度；迭代求解器残差应被记录并解释。
- **S 参数**：实部、虚部和 dB 值有限。
- **场输出**：VTU 文件可打开，场分布不出现明显非物理异常。

## 文档检查

- **行为变化**：新增或改变的 CLI、输出、求解器行为已同步记录。
- **路径变化**：文档路径和实际文件结构一致。
- **专题索引**：新增专题文档已加入相应 `README.md`。
