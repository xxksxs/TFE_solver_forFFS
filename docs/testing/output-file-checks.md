# 输出文件检查

本文说明求解完成后应检查的输出文件。

## S 参数 CSV

检查 `s_parameters.csv`：

- 包含表头。
- 每个求解频点对应一行。
- 实部、虚部和 dB 列均为有限数值。
- 频率列使用 Hz。

## VTU 场文件

检查 `field_last.vtu` 是否存在，并能被 VTK 兼容工具打开。

涉及场重构修改时，还应检查：

- 矢量场空间分布是否合理。
- 场不应在驱动端口之外全为零。
- 端口附近场型应与激励和吸收边界一致。

## 逐频点场文件

使用 `--write-all-fields` 时，应为每个频点写出对应 VTU 文件，并保留 `field_last.vtu` 作为最后一个频点的快捷输出。
