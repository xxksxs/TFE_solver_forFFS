# 建议补充的单元测试

本工程目前还没有完整单元测试框架。本文列出后续建议补充的测试方向。

## AEDT 解析测试

验证内容：

- 材料名称和参数。
- 扫频范围和频点。
- 端口 faceId。
- 激励幅度和相位。

## NGMesh 解析测试

验证内容：

- 点数量和坐标。
- 表面三角形数量。
- 四面体数量。
- faceId 提取。
- facet 信息解析。

## 边拓扑测试

使用极小四面体网格验证：

- 唯一边数量。
- 局部边到全局边映射。
- `localNodes` 是否在生成时按全局点号小到大存储。
- 零阶边基函数交换端点后的符号等价性。
- 一阶边基函数交换端点后的不变性。

## 端口模式测试

在简单矩形端口上验证：

- 非零模式 DOF。
- 模态范数有限且非零。
- 截止值与几何尺寸定性一致。

## 稀疏矩阵测试

验证：

- `add`。
- `multiply`。
- 预构建 CSR pattern 下 `add` 是否落在正确固定位置。
- `imposeDirichlet`。
- `imposeZeroDirichlet` 批量清理受约束行列。
- Dirichlet 对矩阵和 RHS 的同步影响。

## 求解器测试

使用小型已知复数线性系统比较：

- MKL PARDISO 结果。
- 同一稀疏结构下 PARDISO symbolic analysis 复用。
- BiCGSTAB fallback 结果。
- 残差计算。

## 后处理测试

使用合成模态场验证：

- S 参数投影。
- CSV 字段。
- VTU 输出结构。
