# S 参数验证

S 参数由求解后的边自由度投影到端口模式得到。

## 基本检查

对无源双端口问题，通常应满足：

- `S11_dB` 和 `S21_dB` 为有限值。
- 除非确实处于强阻带或激励失败，`S21_dB` 不应无理由接近 `-500 dB`。
- 考虑损耗和数值误差后，能量关系应定性合理。

## 优先排查方向

如果 S 参数异常，优先检查：

- 求解残差是否过高。
- 端口 faceId 是否匹配。
- RHS 激励是否非零。
- 端口边是否被 PEC 清零。
- `PortModeSolver`、`FEMAssembler` 和 `ResultExtractor` 的模态归一化是否一致（L2 模式形状 + 坡印廷功率归一化两层）。
- 无源情形下 `|S11|² + |S21|² ≤ 1` 应成立。如果显著大于 1，多半是 `PortModeSolver`（求积缓存）/ `FEMAssembler`（入射幅度）/ `ResultExtractor`（投影分母）三处的 `powerNormalizationFactor` 不一致。

## 本地回归参考

此前 MKL 直接求解的单频点检查显示传输不再接近数值零。该结果可作为本地回归参考，但不是严格解析基准。
