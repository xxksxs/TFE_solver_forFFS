# 残差预期

残差是判断求解结果可信度的第一检查项。

## MKL PARDISO

矩阵结构合理时，MKL PARDISO 直接求解残差应接近机器精度。

如果残差异常，应优先检查：

- CSR 转换是否正确。
- 矩阵行列尺寸是否等于全局边数。
- Dirichlet 约束是否正确施加。
- RHS 是否非零且有限。

## BiCGSTAB fallback

BiCGSTAB 残差取决于矩阵条件和迭代次数。残差高时，场值和 S 参数不可信。

不要只通过增加最大迭代次数掩盖问题，应先检查：

- 矩阵病态程度。
- 预条件器。
- 端口边界和 PEC 约束。
- RHS 激励是否有效。

## 判断原则

如果残差高，应先排查求解器收敛、矩阵条件、边界条件和 RHS，而不是优先修改场可视化或 S 参数公式。
