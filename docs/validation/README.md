# 数值验证文档索引

本目录用于确认电磁结果是否可信。测试确认程序能运行，验证确认结果有物理意义。

## 阅读顺序

1. **最小验证运行**：阅读 `minimum-run.md`。
2. **残差预期**：阅读 `residual-expectations.md`。
3. **端口验证**：阅读 `port-validation.md`。
4. **S 参数验证**：阅读 `s-parameters.md`。
5. **场可视化验证**：阅读 `field-visualization.md`。
6. **材料和单位检查**：阅读 `material-units.md`。
7. **失败特征**：阅读 `failure-signatures.md`。
8. **验证流程**：阅读 `validation-workflow.md`。

## 文档列表

- **`minimum-run.md`**：单频点最小验证命令。
- **`residual-expectations.md`**：直接求解和 fallback 的残差判断。
- **`port-validation.md`**：faceId、端口模式和激励检查。
- **`s-parameters.md`**：S 参数合理性判断。
- **`field-visualization.md`**：VTU 场图检查。
- **`material-units.md`**：材料和单位一致性。
- **`failure-signatures.md`**：常见失败现象和优先排查方向。
- **`validation-workflow.md`**：物理修改后的推荐验证流程。
